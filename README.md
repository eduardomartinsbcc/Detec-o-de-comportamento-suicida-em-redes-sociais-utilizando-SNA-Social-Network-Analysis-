# Detec-o-de-comportamento-suicida-em-redes-sociais-utilizando-SNA-Social-Network-Analysis-
Muitos trabalhos sobre risco suicida em redes sociais analisam o texto de cada post isoladamente. Nossa pesquisa olha para
as relações entre os posts: montamos redes em que cada post é um nó e as ligações vêm de palavras em comum, de significado
parecido, de fatores psicossociais compartilhados ou do histórico de um mesmo usuário. O objetivo é verificar se a
estrutura dessas redes revela padrões ligados ao nível de risco. Até aqui construímos e visualizamos as redes; a análise
estatística é o próximo passo.
